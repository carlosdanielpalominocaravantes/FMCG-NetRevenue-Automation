# FMCG-NetRevenue-Automation
Pipeline de datos en Python y Dashboard ejecutivo en Power BI para la conciliación masiva de ingresos y auditoría de tránsito contable.
# Automatización de Conciliación de Ingresos y Auditoría de Tránsito (FMCG) 🚀📊

Un ecosistema integral de ingeniería de datos y Business Intelligence diseñado para eliminar los flujos manuales de conciliación contable (SAP vs. MicroStrategy/Synapse) y auditar el cumplimiento de políticas globales de reconocimiento de ingresos.

### 🛠️ Componentes Técnicos y Arquitectura
* **Ingeniería de Datos (Python / Pandas / NumPy):** Ingesta, limpieza y conciliación automática de registros transaccionales multi-sistema, reduciendo el tiempo de procesamiento operativo de horas a milisegundos.
* **Auditoría y Cumplimiento Logístico:** Desarrollo de un algoritmo de seguimiento de tiempos de entrega (*Lead Times*) para identificar desviaciones críticas bajo normativas financieras corporativas.
* **Inteligencia de Negocios (Power BI / DAX):** Creación de un cuadro de mando ejecutivo interactivo con métricas avanzadas (Net Revenue, Desviaciones Financieras de $14M aisladas y porcentaje de alertas en tránsito).

### 📈 Estructura del Repositorio
* `Conciliacion_Automatizada.ipynb`: Cuaderno de Google Colab con el motor del algoritmo en Python.
* `Reporte_Consolidado_Financiero.csv`: Base de datos final procesada y conciliada.
* `Dashboard_NetRevenue.pbix`: Archivo interactivo de Power BI listo para su visualización.
